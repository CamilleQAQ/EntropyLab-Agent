# 代表性实验

以下结果用于展示三个工程能力。每项结果对应其数据集、指标和评估协议。

| 实验 | 对照与设置 | 结果 |
| --- | --- | --- |
| [预算感知选型](14_seconds_budget.md) | 三轴轴承 7 类任务，5 个分组划分。Agent、固定顺序和随机搜索使用 60 秒预估特征提取预算，另设无预算上限的穷举参照 | Agent 花费 37.6 秒预估成本，平均验证 Macro-F1 0.9500。固定顺序 0.8326，随机搜索 0.8957，穷举 0.9500 |
| [特征工具验收](21_research_lab.md) | CWRU 4 类任务，5 个录制级划分。两组使用相同划分、基础特征和 ExtraTrees 分类器，候选组增加生成的包络谱特征 | 平均验证 Macro-F1 从 0.9571 提升至 0.9715，配对均值增加 0.0144 |
| [持续更新](18_v2_decision_layer.md) | Paderborn 3 类任务，5 个测量级分组划分。比较仅用初始批次训练的冻结模型和按工况逐批更新的模型 | 独立留出集准确率平均提高 3.51 个百分点，3 个划分提升，2 个持平 |

划分结果用于同一数据集内的配对比较。三轴轴承和 CWRU 表格记录的是验证集指标，Paderborn 记录的是严格按时序决策后的留出集指标。测量级划分的结果适用于该数据集和测量级协议，跨物理轴承泛化需要单独评估。

复现入口见上表链接。各脚本使用本地准备的数据，并写出配置、划分和指标供检查。生成式工具的验收数字对应一次具体的候选注册，重新生成时，候选代码和得分可能变化。
